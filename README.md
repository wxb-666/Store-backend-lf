# 伪 Shopify 店铺后台

基于 Vue 3 + Vite 开发的 Shopify 风格店铺后台界面。

## 当前版本

| 版本      | 状态   | 版本说明                             |
|---------|------|----------------------------------|
| v0.1.0  | 开发中  | 完成订单列表页与订单明细页前端界面，并通过后端接口获取页面数据。 |

## 项目结构

| 目录/文件                  | 说明                |
|------------------------|-------------------|
| `fe/`                  | Vue 3 + Vite 前端项目 |
| `be/`                  | 后端接口与业务服务         |
| `Shopify截图/`           | Shopify 后台界面参考截图  |
| `docker-compose.yml`   | 本地容器化开发配置         |

## 克隆与部署

部署前，请先安装并启动 Docker Desktop，确认 Docker 服务处于运行状态。

1. 克隆仓库并进入项目目录：

   ```bash
   git clone <仓库地址>
   cd Store-backend-lf
   ```

2. 首次构建并启动前后端容器：

   ```bash
   docker compose up -d --build
   ```

   > 该命令会构建前后端镜像、创建容器，并根据 `fe/package-lock.json` 自动安装 Vue、Vite 及其他前端依赖。  
   > 创建完容器后，后续运行时，只需输入 "docker compose up -d" 即可。

3. 服务启动后，访问前端页面：`http://localhost:5173`。

   后端容器映射端口 `8000`；当前用于提供后端开发运行环境，待 API 实现后即可通过该端口提供接口服务。

后续仅需启动已有容器时，可执行：

```bash
docker compose up -d
```

停止服务可执行：

```bash
docker compose down
```

## 开发说明

前端与后端代码分别位于 `fe/` 和 `be/` 目录。启动方式及接口配置以各子项目内的配置文件为准。
